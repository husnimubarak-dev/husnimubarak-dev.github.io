# Husni Mubarak — Portfolio

Light-theme static portfolio for GitHub Pages.

## Stack
- HTML
- Tailwind CSS via CDN
- Vanilla JavaScript
- GitHub Pages

## Deployment
Zero-build. The repository root is uploaded directly by `.github/workflows/deploy.yml`.
The deployed artifact contains `index.html` at its root.

## Update
Edit `index.html`, commit, and push to `main`.
